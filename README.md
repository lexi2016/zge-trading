# Z哥交易体系 (zge-trading)

基于zettaranc"大富翁小菜鸟"公众号的股票交易战法体系。

## 核心战法

### B1/B2/B3买点

| 买点 | 条件 | 场景 |
|------|------|------|
| B1 | J≤13 + 量比<0.8 + 白线>黄线 + 股价>白线 | 超跌反弹 |
| B2 | 涨幅>4% + 放量 + J<55 + 白线>黄线 | 突破启动 |
| B3 | 收盘价创15日新高 + 量比<0.7 | 追涨 |

### 核心指标

- **白线**：短线生命线 = 牵牛绳
- **黄线**：知行多空线 = 大哥线
- **BBI**：多空线

### 风控规则

- 止损：B1跌破K线最低点下方3-5个点
- 止盈：BBI线上两根中大阳线减仓
- 过滤：一波流（涨幅>30%）、累计换手>150%
