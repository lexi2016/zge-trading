# 选股条件详解

## B1买点（超跌反弹）

### 必要条件
1. **J值 ≤ 13** - KDJ指标，股价超跌
2. **量比 < 0.8** - 缩量，抛压减轻
3. **白线 > 黄线** - 短期趋势向上
4. **股价在白线上** - 站上短期均线
5. **涨幅 -2% ~ +1.8%** - 区间震荡

### 选股步骤
1. 股价站上N型结构的均线
2. 已形成缩量波幅的K线
3. 均线和多头排列判断趋势位置
4. 均线和B1匹配的趋势
5. 均线和卖点/止损位置
6. 均线没有形成头肩顶

### B1开盘买入策略
| 量比 | 状态 | 操作 |
|------|------|------|
| 低量比(<10) | 正常 | 等回调慢买 |
| 高量比(≥20) | 开盘上涨 | 直接介入 |
| 高量比(≥20) | 开盘大跌 | 观望 |
| 中量比(7~16) | 量价同步涨 | 介入 |
| 中高量比(≥10) | 大幅低开(-2%以下) | 观望 |

## B2买点（突破启动）

### 必要条件
1. **B1之后** - 股价已处于相对低位
2. **涨幅 > 4%** - 强势信号
3. **前一日放量** - 量能配合
4. **J < 55** - 尚未超买
5. **股价在BBI线上方** - 趋势向上

### B2三大暴利图形
1. **平行重炮** - K/N相对平行位置放量长阳
2. **灾后重建** - K/N缩量踩大哥线震仓后启动
3. **跃跃欲试** - K/N横盘放量中大阳

## B3买点（追涨）

### 必要条件
1. **收盘价创15日新高** - 趋势强劲
2. **量比 < 0.7** - 缩量上涨，筹码稳定
3. **涨幅 -2% ~ +2%** - 刚启动
4. **股价在BBI线上方** - 趋势向上

## 过滤条件

### 必须过滤
- 近30日最大涨幅 > 30% → 一波流
- 累计换手率 > 150% → 主力出货
- 带跳空缺口的建仓票 → 游资行为
- 换手率超标的斜率票 → 不确定性高

### 分时图陷阱
- 开盘30秒直线拉升 → 不追
- 开盘30秒急跌超4%且放量破黄线 → 止损
