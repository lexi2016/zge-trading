# 风控规则详解

## 止损规则

### 基础止损
- **B1**：跌破K线最低点下方3-5个点
- **B2**：N型结构前低
- **B3**：突破大阳线的中间位置

### 短线止损补充
1. 赚钱的票快速回到成本价 → 立即卖出
2. 买入后该涨不涨，成本区附近/微亏 → 立即卖出
3. 收盘破止损价格 → 立即卖出

### 强制离场条件
- 连续两日收盘跌破BBI线
- 白线死叉黄线，次日无法收回
- 单日跌幅≥2.3%

## 止盈规则

### 常规止盈
- **少妇战法**：BBI线上两根中大阳线，减仓
- **双线战法**：白线牵牛绳，不破白线不卖；加速后逐步放飞

### 放飞策略
- 浮盈>10% + S1信号 → 卖出一半
- 收盘不破白线 → 另一半继续持有
- 跌破白线 → 全清
- 每一根大长阳拉起来，就放飞一点（1/2 → 1/4 → 1/8）

## 防卖飞策略

### 每日持股检查
1. 忽略盘中冲高回落！冲刺阶段多为1~2日小洗盘
2. 下杀后观察：尾盘/次日是否快速收回
3. 禁止下杀中卖出，仅在止损位触发时卖出
4. 收盘缩量小阴线，持有再观察1日
5. 完美形态标的，不破BBI线则坚定持有
6. 多看日线：收盘价持续提高则持有

### 大跌后次日操作
- 10点前快速拉升反弹 → 至少减仓50%
- 前一日冲高回落 + 次日低开≥2% → 直接清仓

## 手紧手松原则

### 手紧原则（空头趋势）
- 大盘在黄线下
- 活跃市值在-2.3%波段内
- 仅做B1，仓位0-50%
- 不涨就卖、托起来就卖、止损到价就卖

### 手松原则（多头趋势）
- 大盘在白线上
- 活跃市值在+4%波段内
- B1/B2/B3/补票都可做，仓位80-100%
- 拿住不动、逐步放飞

## 主力出货信号

### 五大出货形态
1. 加速后单日放天量大阴线
2. 加速后次高点突然巨量长阴
3. 新高后连续阶梯放量下跌
4. 双头双放量巨阴
5. 顶部绿长红短

## 心态管理

### 五种思维要删除
1. 交易目标错误 → 应树立"轻易不亏钱"
2. 被市场噪音吸引注意力
3. 想赢怕输
4. 线性思维
5. 策略执行不坚定

### 五种思维要建立
1. 核心目标：轻易不亏钱
2. 聚焦自身持仓
3. 完美图形做错也要执行
4. 承认市场不确定性
5. 坚持1-2种顺手的战法
