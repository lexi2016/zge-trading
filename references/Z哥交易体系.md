## 一、核心基础战法体系

### 1.1 少妇战法1.0（六步流程）

1. **择时** - 经济周期+政策指引+增量资金+入场时机
2. **选股** - 政策+行业+龙头公司+资金+估值
3. **等B1** - 主题等日线B1、主线等周线B1
4. **设止损** - 当根K线最低点下方、N型结构上一个低点
5. **止盈放飞** - BBI线上两根中大阳线减仓
6. **离场** - 连续两日收盘跌破BBI线

**短线止损补充规则**：
- 赚钱的票快速回到成本价 → 立即卖出
- 买入后该涨不涨，成本区附近/微亏 → 立即卖出
- 收盘破止损价格 → 立即卖出

### 1.2 深V玩法（补票战法）

- **核心定位**：错过B1买点的超短线补票策略
- **适用场景**：N型结构连续上升、BBI线趋势向上的标的
- **盈亏比**：3:1，浮盈±2%/4-6%为关键阈值

**操作步骤**：
1. 前晚完成选股，次日早盘介入
2. 持有1个交易日必须脱离成本线，未脱离则次日开盘卖出
3. 脱离成本线3%以上，可酌情持有或减半仓
4. 持有过程切换为少妇战法，BBI线下执行卖出策略

**核心原则**：买入后当期K线必须上涨，不涨即判定操作错误！

### 1.3 双线战法（白线+黄线）

**双线定义**：
- **白线（短期趋势线）** = 短线生命线 = 牵牛绳，不破则持有，跌破则短期趋势走坏
- **黄线（知行多空线/大哥线）** = 主力入场标志，极限洗盘位，控盘成本线，线下无右侧交易价值

**核心使用逻辑**：
1. 右侧交易仅做「白线在黄线上」的标的
2. 白线金叉黄线 → 上涨趋势确立，等回踩B1入场
3. 白线死叉黄线 → 最后离场时机，无条件执行
4. 白黄线将死未死 + N型结构不破 + J大负值 → 极限买点，仅接受1根K线止损
5. 横盘震荡期 → 切换为顶部压力线/底部支撑线评估买卖点

**循环操作法**：
B1买入 → 横盘/温和上涨持有 → B1+白黄区间加仓 → 加速后放飞 → 跌破白线卖出 → 观察黄线区间价值 → 重新B1买入

### 1.4 对称战法

**核心理论**：物理学对称性支配相互作用，仅在「守恒被破坏的位置」有交易价值

**对称分类**：
- 时间对称：上升周期 VS 下降周期
- 空间对称：直接对称 VS 间接对称
- 形态对称：轴对称 VS 中心对称

## 二、复盘与选股体系

### 2.1 标准化复盘步骤

1. **看新闻** - 提取信息/政策/风向，甄别舆情噪音
2. **看大盘** - 判断市场整体走势、指数趋势
3. **看热点** - 区分主线/主题，判断持续性、新热点出现、旧热点退潮
4. **看持仓** - 验证持有逻辑，盯盘面关键点，识别买卖/加减仓时机
5. **选股** - 手动筛选 + 自动筛选结合

**复盘落地**：制定次日交易计划，明确「仓位管理+买/卖决策+买卖量」

### 2.2 选股核心规则

**通用选股原则**：
1. 放弃「看似安全标的」，选择高风险高潜力标的
2. 清除主观偏好，不排斥不知名/认知弱的标的
3. 同板块内选最强：最早上攻、开盘量比最大且同步上涨
4. 多选一易出错时，可采用板块全买策略

**最强B1标的筛选标准**：
1. 符合完美图形模板
2. 成交量：相比前高放量，当期极致缩量K线
3. 涨幅：-2% ~ 1.8%
4. 振幅：7%以内
5. 指标：白线＞黄线

**牛市ETF选股策略（躺平策略）**：
- 前提：牛市强趋势开启 + 增量资金持续 + 不会选股/怕踏空
- 策略：主线ETF + 主题ETF组合配置
- 执行：B1买入 + 波段持有 + 波段切换

## 三、关键K线选股法

### 3.1 关键K线核心价值

仅在关键点做交易，K线分为四类：
- 趋势反转
- 大资金入场
- 大资金离场
- 走势衰竭

### 3.2 底部暴力K线（擒大牛）

**核心价值**：趋势扭转/改变/延续

**触发条件**：
1. 位置：绝对底部/相对底部/趋势中B1位置
2. 形态：突兀、莫名其妙的异动（平地惊雷）
3. 量价：越大长阳、越大倍量越好
4. 时机：市场让交易者产生恐惧的时间/位置

### 3.3 击穿对手盘选股

**定义**：缩量/连续缩量破短线对手盘止损位

**核心武器**：长阴短柱、低位缩量横盘、小幅放量难看阴线

**观察依据**：
- 前期有强异动（倍量柱/关键K越多越好）
- 顶部缩量下跌至地量，且不破自身止损位

## 四、择时与增量资金判断

### 3.1 择时三要素（天时+地利+人和）

1. 宏观经济周期（天时）
2. 政策周期（地利）
3. 增量资金（人和）：监测利率、MLF，跟踪资金主体

### 3.2 增量资金判断

**活跃市值入场信号**：
- 小波段4%阳线 → 跟增量资金做主题
- 大波段5~8%阳线 → 主线/主题均可做
- 连续7~20%阳线 → 随意买，长期持有

**活跃市值离场信号**：
- 单日跌幅≥2.3% → 大概率波段结束，执行减仓/清仓

### 3.3 填坑择时策略

**坑的分类**：
| 坑类型 | 特征 | 策略 |
|--------|------|------|
| 大坑 | 有前历史新高，长期下跌后企稳 | 大波段，拿住不动 |
| 小坑 | 有阶段高点，回调后企稳不破前低 | 少妇战法 |
| 小洞 | N型上升趋势中黑天鹅下杀 | 快进快出 |

## 五、B1/B2/B3交易体系

### 5.1 核心定义

- **B1** - 不同时间周期的阶段低点位置（超跌反弹）
- **B2** - 不同时间周期的B1低点确认阳线位置（突破启动）
- **B3** - B2后的中继位置（追涨）

### 5.2 核心属性对比

| 属性 | B1 | B2 | B3 |
|------|----|----|-----|
| 盈亏比 | 最大 | 中 | 最小 |
| 上涨确定性 | 最差 | 中 | 最好 |
| 止损幅度 | 最大 | 中 | 最小 |

### 5.3 买入后走势期待

- **B1**：3个交易日内恢复上涨
- **B2**：2个交易日内必须大幅拉升
- **B3**：不破B3阳线最低点即可持有

### 5.4 止损设置规则

- **B1**：买入K线最低点，或向下3~5个价位
- **B2**：N型结构前低
- **B3**：突破大阳线的中间位置

### 5.5 B2三大暴利图形

1. **平行重炮** - K/N相对平行位置放量长阳
2. **灾后重建** - K/N缩量踩大哥线震仓后启动
3. **跃跃欲试** - K/N横盘放量中大阳

### 5.6 B1开盘买入规则（量比为核心）

| 量比 | 价格状态 | 操作策略 |
|------|----------|----------|
| 低量比(＜10) | 正常 | 等回调慢买 |
| 高量比(≥20) | 开盘上涨 | 直接介入 |
| 高量比(≥20) | 开盘大跌 | 观望 |
| 中量比(7~16) | 量价同步涨 | 介入 |
| 中高量比(≥10) | 大幅低开(-2%以下) | 观望 |

**软件量比换算**：东财=通达信-1~3；同花顺=通达信/2

## 六、交易执行与风控体系

### 6.1 标准化交易执行流程

- **盘前**：完成选股（明确B1/B2/B3）
- **盘中**：根据量比/价格走势执行买卖，明确盈亏比、止损位
- **盘后**：判断持有逻辑，执行止损/止盈/加仓/减仓

### 6.2 止盈/离场规则

**常规止盈**：
- 少妇战法：BBI线上两根中大阳线，减仓
- 双线战法：白线牵牛绳，不破白线不卖；加速后逐步放飞

**强制离场**：
- 连续两日收盘跌破BBI线
- 白线死叉黄线，次日无法收回
- 单日跌幅≥2.3%

### 6.3 防卖飞策略（每日持股检查手册）

1. 忽略盘中冲高回落！冲刺阶段多为1~2日小洗盘
2. 下杀后观察：尾盘/次日是否快速收回
3. 禁止下杀中卖出，仅在止损位触发时卖出
4. 大盘下杀时，不草率卖出当日强势同步下杀的标的
5. 收盘缩量小阴线，持有再观察1日
6. 完美形态标的，不破BBI线则坚定持有
7. 多看日线：收盘价持续提高则持有

**持股标的分类**：
- 特级马/一等马：收盘价持续上升，拿住不动
- 低等马：横盘不破止损，持有观察
- 草泥马：买入后出现SB1/触发止损，立即卖出

### 6.4 大跌后次日操作

1. 10点前快速拉升反弹 → 至少减仓50%
2. 前一日冲高回落 + 次日低开≥2% → 直接清仓

### 6.5 大盘回调期标的筛选（弃弱留强）

**四类强势标的**：
1. 持续上涨的标的（趋势延续）
2. 跌幅小且保持在BBI线上的标的（趋势未变）
3. 同步下跌但跌幅小，缩量后放量反弹的标的（趋势未坏）
4. 同步大跌但反弹弱/创新低的标的（趋势结束，果断卖出）

### 6.6 主力出货五大典型方式

1. 加速后单日放天量大阴线
2. 加速后次高点突然巨量长阴
3. 新高后连续阶梯放量下跌
4. 双头双放量巨阴
5. 顶部绿长红短

## 七、仓位与交易节奏管理

### 7.1 仓位管理规则

**小资金增值（2万本金）**：
| 目标 | 持仓数量 | 最大回撤 | 周期 | 类型 |
|------|----------|----------|------|------|
| 100万 | 1只/日，满仓 | 50~70% | 2~5年 | 波段 |
| 10万 | 2只/日，满仓 | 30~50% | 1~3年 | 波段+短线 |
| 5万 | 3只/日，满仓 | 15~25% | 3个月 | 超短 |

**通用仓位**：
| 资金规模 | 持仓数量 | 操作要求 |
|----------|----------|----------|
| ＜100万（高手） | 4~5只 | 分仓波段，重仓短线 |
| ＜100万（新手） | 10只 | 分仓为主 |
| 500万 | 10只 | 均衡分仓 |
| 1000万 | 15~20只 | 分散分仓 |

### 7.2 交易节奏管理

**节奏分层**：
- 市场节奏：货币宽松/紧缩周期；上涨/下跌/横盘
- 板块节奏：无人问津/人声鼎沸/主升阶段
- 个股节奏：建仓波/拉升波/冲刺波/垃圾时间

**盈利目标**：
| 资金规模 | 盈利目标 |
|----------|----------|
| ＜10万 | ≥100% |
| 10~50万 | 70~100% |
| 50~100万 | 50~70% |
| 100~300万 | 30~50% |
| ≥500万 | 10~20% |

### 7.3 Z家军每日5步工作流

1. **择时（1min）** - 监测活跃市值，关注4%/-2.3%阈值
2. **定策略（2min）** - 判断松紧，选择策略组合(B1/B2/B3/补票)
3. **复盘（3min）** - 回顾持仓，识别止损/放飞/加仓标的
4. **选股（5min）** - 按标准选出目标标的
5. **执行（1.2s）** - 开盘竞价后买卖，快收盘前执行卖出

### 7.4 手紧手松原则

**手紧原则（空头趋势）**：
- 大盘在黄线下
- 活跃市值在-2.3%波段内
- 仅做B1，仓位0~50%

**手松原则（多头趋势）**：
- 大盘在白线上
- 活跃市值在+4%波段内
- B1/B2/B3/补票都可做，仓位80~100%

## 八、成交量核心用法

### 8.1 量能类型及价值

| 类型 | 价值 |
|------|------|
| 放量 | 仅在上涨过程中有交易价值 |
| 缩量 | 上涨回调阶段缩量越多越好（趋势未完） |
| 平量 | 大概率趋势延续 |
| 地量 | N型结构上涨阶段地量配合B1为买点 |

### 8.2 量能与K线配合

- 上涨放量 → 确认趋势，资金入场
- 回调缩量 → 洗盘，趋势未结束
- 底部倍量暴力K → 趋势反转，大牛股信号
- 顶部天量阴线 → 主力出货，趋势结束

## 九、散户思维改造与心态

### 9.1 必须删除的5种思维

1. 交易目标错误（应树立「轻易不亏钱」）
2. 被市场噪音吸引注意力
3. 想赢怕输
4. 线性思维
5. 策略执行不坚定

### 9.2 必须建立的5种思维

1. 核心目标：轻易不亏钱
2. 聚焦自身持仓，不被其他标的上涨干扰
3. 完美图形标的，即使做错也要执行
4. 承认市场不确定性，只相信盘面
5. 交易初期，坚持1~2种顺手的战法

### 9.3 核心心态原则

1. 不对股票产生感情，尊重盘面
2. 止损果断，仅接受1根K线的止损损失
3. 赚钱的票不做亏，盈转亏必卖
4. 踏空是策略的一部分
5. 买卖不犹豫，下一个标的更重要

## 十、波段与超短线专项策略

### 10.1 波段战法（7步曲）

1. 选周线白线之上，N型结构上涨区间的标的
2. 选有大资金布局的标的
3. 用周线级别均线关系判断入场位置
4. 日线级别匹配B1入场点
5. 周线级别设置均线为止损位
6. 日线级别执行放飞和卖出
7. 周线趋势未改变则盯住反复操作

**波段每日三问**：
- 做的是波段还是超短线？
- 做的是左侧还是右侧？
- 是否出现放量阴线？

### 10.2 超短线战法（10万以下）

**执行规则**：
1. 标的筛选：股价在黄线上 + 绿转强红（≥2/3）
2. 买入时机：当日尾盘买，或次日早晨不追高买
3. 仓位管理：10万分两仓，5万/个
4. 止损规则：买入K线最低价，或两日内未拉升即卖出
5. 止盈规则：脱离成本区≥5%，持仓最多4~6天

**口诀**：赚钱就拿，积小成多；不给就走，不问原因；永不完美，踏空正常

## 十一、麒麟会运作阶段识别

| 阶段 | 走势特征 | 仓位变化 | MACD指标 |
|------|----------|----------|----------|
| 建仓 | 低位连续上涨，无介入机会 | 持续增加 | 绿变红 |

### 标的分类

| 分类 | 行业/板块 |
|------|-----------|
| 老登（稳） | 白酒、煤炭、有色、化工、银行、券商、稀土、锂矿、保险 |
| 中登（成长） | 新能源车、金融科技、大科技 |

### 仓位配色
- 绿色：筑底
- 黄色：趋势中
- 红色：高位震荡
